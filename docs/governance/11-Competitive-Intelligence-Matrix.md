## Key Questions to Answer

### 1. Offline Capability
- Does it work without internet?
- If yes, for how long?
- Does it sync when internet returns?
- Does it handle conflicts?

### 2. Pricing Accessibility
- Is it affordable for a 10-room hotel?
- Is pricing in local currency?
- Are there hidden costs (per-user, per-property, integrations)?

### 3. AI Features
- What AI features exist (if any)?
- Are they useful or gimmicky?
- What's the cost premium for AI?

### 4. Local Market Fit
- Is it designed for Nigerian/African market?
- Does it handle local payment methods?
- Is support available locally?

### 5. Ease of Use
- How long does training take?
- Is it usable by non-technical staff?
- What's the learning curve?
